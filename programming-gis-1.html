Programming for Geospatial I - Practical Reflection

In this task, I learned how to create buffers in ArcGIS Pro, first manually and then with arcpy code. I started with the Buffer tool in the Geoprocessing panel, where I chose the road layer, set the distance to 100 meters, and ran it. I also learned that the layer should use a projected coordinate system, because a layer in degrees gives a wrong buffer.

While doing this, I faced many errors, and solving them was difficult, but I managed to fix them and that helped me understand the tool better. Then I moved to arcpy, where I stored the road layer and the distance in separate variables and ran the Buffer function in the Python Window. This showed me that code can do the same work as the tool, and that I can change only the distance to get 100, 200 and 500 meter buffers.

I also learned that a loop can create these buffers for roads, buildings and waterbodies together, which saves a lot of time. Overall, this task improved my confidence in both GIS tools and basic Python, and showed me how buffers help in analysing the area around features.
